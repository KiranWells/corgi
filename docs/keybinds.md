# Keybinds

| Keybind        | Action     | Details                         |
| :------------- | :------    | :------------------------------ |
| `Ctrl-S`       | Save       |                                 |
| `Ctrl-Shift-S` | Save As    |                                 |
| `Ctrl-O`       | Open       | Supports `.corg` or image files |
| `Ctrl-Q`       | Quit       |                                 |
| `Ctrl-Shift-Q` | Force Quit | Skips the save prompt           |
| `Escape`       | Cancel     | Cancel an active render         |
| `Ctrl-C`       | Cancel     | Cancel an active render         |
| `Ctrl-Z`       | Undo       |                                 |
| `Ctrl-Shift-Z` | Redo       |                                 |
| `Ctrl-Y`       | Redo       |                                 |

> [!TIP]
> Certain widgets support copy and pasting special data. For example, pasting a share string or image settings in the main viewport will load the pasted settings.
